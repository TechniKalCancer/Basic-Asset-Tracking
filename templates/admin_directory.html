Reads users and computers from AD and attaches them to the people and devices FoxDesk already has: an AD account becomes another account on the person's profile (matched by email), and an AD computer is matched to its device by serial number or computer name. It never creates people or devices and never writes to AD. Anything it can't match with certainty waits for you to review.

{% if not configured %}

Set up

  1. In AD, create a service account that is only in Domain Users. It needs no admin rights or delegation; any domain user can read users and computers.
  2. Give each domain controller an LDAPS certificate (port 636). A self-signed certificate is fine: you'll compare its thumbprint here before FoxDesk trusts it.
  3. Add these to .env on the FoxDesk server and restart the container: 
    AD_SERVERS=dc1.yourdistrict.org,dc2.yourdistrict.org
AD_BASE_DN=DC=yourdistrict,DC=org
AD_BIND_USER=svc-foxdesk@yourdistrict.org
AD_BIND_PASSWORD=<the account's password>
    Use letters and digits only in the password: Docker treats $ in .env as a variable.
