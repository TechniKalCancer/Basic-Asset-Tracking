🔗 Google Workspace Sync Setup

{{ 'Configured' if google_sync_enabled else 'Not Configured' }} ← Back

Google requires a human Workspace super admin to manually authorize this app's service account in the Domain-wide Delegation console — there's no API for that step, so this page can't do it for you. What it can do: give you the exact links in the right order, and a real connectivity test at the end so you know it actually worked instead of guessing.

Setup Checklist

  1. Create (or select) a Google Cloud project ↗ — any project works, it just needs to belong to your organization.
  2. Enable the Admin SDK API ↗ on that project (click "Enable" if it isn't already).
  3. Create a service account ↗ — any name/description is fine, no roles need to be granted on the Cloud project itself.
  4. On that service account's page, open the Keys tab → Add Key → Create new key → JSON, and download it. Then open the Details tab and copy the Unique ID (a long number) — that's the Client ID you'll need next.
  5. Authorize Domain-wide Delegation ↗ in the Workspace Admin console → Add new → paste the Client ID, and for OAuth scopes paste (comma-separated, on the same entry — not two separate ones):
    https://www.googleapis.com/auth/admin.directory.device.chromeos.readonly {% if google_loaner_autodisable_enabled %}
    https://www.googleapis.com/auth/admin.directory.device.chromeos{% endif %}
    Always include the .readonly scope. Only add the second (non-readonly) scope if you want the loaner auto-disable feature — it's a bigger blast radius (it can remotely disable a live device), so only add it if you're actually going to use it.
  6. Get the downloaded JSON key file onto the server where this app runs, and point GOOGLE_SERVICE_ACCOUNT_FILE at it in .env. If you're running via Docker Compose, drop the file into a google-credentials/ folder next to your docker-compose.yml (already mounted read-only into the container at /app/instance/google-credentials/) and set:
    GOOGLE_SERVICE_ACCOUNT_FILE=/app/instance/google-credentials/<your-key-filename>.json
    GOOGLE_ADMIN_IMPERSONATE_EMAIL=<a real super admin's email on your domain>
    Then restart the container (docker compose up -d --force-recreate web).
  7. Click Test Connection below.
