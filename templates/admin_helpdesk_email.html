How to set up Microsoft 365
  1. In the Entra admin center: App registrations → New registration ("FoxDesk help desk", single tenant).
  2. API permissions → Add → Microsoft Graph → Application permissions → Mail.ReadWrite, then Grant admin consent.
  3. Certificates & secrets → New client secret. Copy its value.
  4. Recommended: limit the app to just the help desk mailbox with an Exchange application access policy (New-ApplicationAccessPolicy -AppId <client id> -PolicyScopeGroupId helpdesk@… -AccessRight RestrictAccess).
Google Workspace: turn on IMAP for the mailbox and use an app password.
