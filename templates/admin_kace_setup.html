Pulls device inventory (hostname, OS, manufacturer/model, last-seen time, and more) from a KACE Systems Management Appliance, matching devices onto Asset Registry rows by serial number — same match-only approach as Google Workspace sync: it never creates new registry rows on its own, since KACE's inventory includes plenty of equipment (staff laptops, servers) this district's registry deliberately doesn't track. Logs in through the same session KACE's own admin console uses, so no separate API token is needed — just a KACE account.

Setup

  1. In the KACE admin console, create (or reuse) a user account for this app — a dedicated account with just enough access is safer than reusing your own admin login long-term, though any valid console account with the Administrator role works.
  2. Set these in .env on the server this app runs on:
    KACE_URL=https://<your KACE appliance address>
    KACE_USERNAME=<that account's login name>
    KACE_PASSWORD=<that account's password>
    KACE_ORGANIZATION=Default (only change this if your KACE has more than one organization configured)
    Then restart the container (docker compose up -d --force-recreate web).
  3. Click Test Connection below.
  4. Once connected, head to KACE Field Mapping to choose which KACE fields (hostname, OS, model, etc.) get written onto matched registry rows, then run a sync — manually, or on a timer from Scheduled Syncs.
