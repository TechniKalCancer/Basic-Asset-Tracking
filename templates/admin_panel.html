{{ icon('import') }}Upload Asset Registry CSV

All columns are optional — rows with no asset_tag (and no serial_number to fall back on) get a tag self-assigned automatically: sequential numbers from the default asset number range if one's set, otherwise a random unique 6-digit tag.
Uploading a new CSV completely replaces the entire registry, every site, and auto-heals any orphaned scan records — this is why it's super-admin only. Site admins can fill in devices' sites without replacing anything via Set Sites (CSV) instead.

Accepted column names:
Asset ID or asset_tag — optional, auto-assigned if blank
Serial Number — optional
description — optional
device_type or type — optional, one of: chromebook, laptop, ipad, charger, hotspot, other (defaults to chromebook)

Example (MDM export format):
Asset ID,Serial Number
126295,0UG99FBDA22224
126296,0UG99FBDA22742
