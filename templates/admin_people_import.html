Bulk create or update people in one shot — e.g. a district SIS/HR export at the start of the year. Each row is matched to an existing person by external_id (ID number) first, falling back to email if no ID number is given or matched. A match updates that person's attributes; no match creates a new person. Existing people not present in the CSV are left alone — this never deletes anyone.

Required columns: first_name, last_name, email
Optional columns: external_id (also accepts staff_id/student_id), role (staff/student), department, site, grad_year (also accepts graduation_year)
site must exactly match an existing site's name (see Sites) — required for a new person if you only manage one site or more; an unrecognized name skips that row rather than guessing.

Example:
first_name,last_name,email,external_id,role,site,grad_year
Alex,Rivera,alex.rivera@example.edu,100482,student,Fox Creek Middle School,2031
Jordan,Lee,jordan.lee@example.edu,100483,student,Fox Creek Middle School,2031
