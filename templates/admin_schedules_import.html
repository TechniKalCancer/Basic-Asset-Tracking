Upload the export

Every student in the file gets their whole schedule replaced with what's in it. Students who aren't in the file keep theirs, so you can import one grade at a time.

What the file needs

One row per class per student, with a header row. Column names can be the SIS's own:

  • Student: Student Number (matches the ID on People), or Email, or First and Last Name
  • Period: Period, Expression (PowerSchool, e.g. 1(A)), Block or Hour
  • Optional: Course, Teacher, Room, Term
